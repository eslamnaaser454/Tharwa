# Changelog

## v0.1.0 — Initial Release

- Full Next.js 14 landing page with App Router
- 12 sections: Nav, Hero, Pain, Features, How It Works, Product Preview, Differentiation, Security, Social Proof, Pricing, Final CTA, Footer
- Complete Arabic (AR) and English (EN) localization with next-intl
- RTL layout support with automatic font switching (Inter/Tajawal)
- Localized routing (`/en/...` and `/ar/...`)
- Custom cursor with lerping ring and mix-blend-mode
- Scroll progress bar
- Magnetic buttons with ripple effects
- 3D tilt cards on features, pricing, testimonials, and security cards
- Hero parallax with floating Halal/Zakat badges
- Animated spending chart line (stroke-dashoffset draw)
- Goal bar shimmer on hover
- Pricing toggle (monthly/annual)
- Currency switcher in product preview
- Full accessibility: semantic HTML, aria labels, keyboard navigation, WCAG AA colors
- prefers-reduced-motion support throughout
- Responsive breakpoints: 1100px, 760px
- Tailwind CSS with custom design tokens matching the design prototype
- Framer Motion for scroll-reveal animations
- Lucide React for consistent iconography
